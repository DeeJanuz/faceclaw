## Launch checks

`com.faceclaw.app`, `com.faceclaw.t3`, `com.faceclaw.signal`, and
`com.faceclaw.spotify` each returned `am start -W` status `ok`; their package
processes remained alive after four seconds. The final log scan contained no
`FATAL EXCEPTION`, `AndroidRuntime`, or `Invalid viewport` entry for these
packages. Raw output is preserved at
`output/sdk-independence/device-checks-fixed-20260915.log`.

The first candidate pass exposed a real SDK defect: all SDK-backed services could
crash while configuring a declared but unopened zero-sized host surface. Candidate
`1.1.0-rc.1.9dc05298f50a` guards invalid/zero viewport snapshots, adds two unit
tests, and was rebuilt and installed before this successful launch pass.
